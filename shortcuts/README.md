# YAKMESH Shortcuts

These shortcuts use the yak:// protocol to open YAKMESH interfaces.

## Prerequisites
Run this command first to register the yak:// protocol:
`
yakmesh protocol register
`

## Available Shortcuts
- **Dashboard.url** - Node dashboard with peer connections, identity, and metrics
- **Documentation.url** - Local documentation (works offline)
- **Bookmarks.url** - Saved mesh content
- **Health Check.url** - Quick node health status

## Creating Desktop Shortcuts
Right-click any .url file → Send to → Desktop (create shortcut)

## Direct URLs (when node is running)
- http://localhost:3000/dashboard
- http://localhost:3000/docs/
- http://localhost:3000/health
