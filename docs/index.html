What is YAKMESH?

YAKMESH is a quantum-inspired distributed mesh network with a self-verifying oracle. It provides post-quantum secure peer-to-peer communication with deterministic validation that requires no external trust.

Key Features

  • Post-Quantum Security - ML-DSA-65 signatures (NIST FIPS 204) and ML-KEM-768 key exchange
  • NAMCHE Gateway - 7-gate mathematical identity verification
  • DOKO Identity - Distributed Ownership & Key Object with mesh-verified domain claims
  • SHERPA Discovery - Decentralized peer discovery via public web beacons
  • NAKPAK Routing - Post-quantum onion routing for anonymous communication
  • ANNEX Channels - Autonomous Network Negotiated eXchange with AES-256-GCM
  • 3.0 Communication Stack - GUMBA access control, YURT rooms, KATHA chat, VANI calls, DARSHAN streaming
  • Self-Verifying Oracle - Deterministic validation without trust
  • Mesh Networking - WebSocket P2P with gossip protocol
  • Precision Timing - Atomic clock, GPS, PTP, NTP support
  • Plugin Architecture - BaseAdapter for custom integrations
