YAK:// Protocol

10 min

Share content with cryptographic links that work everywhere

The yak:// protocol lets you create permanent, content-addressed links to your files and folders. These links are cryptographically verifiable and work across the entire YAKMESH network.

🐃 What is yak://?

The yak:// protocol is YAKMESH's content-addressing system. Unlike regular URLs that point to a server location, yak:// links point to the content itself.

  • • Content-addressed: The link is derived from the content's cryptographic hash
  • • Self-verifying: If the content changes, the link changes
  • • Decentralized: Any YAKMESH node can serve the content
  • • Post-quantum secure: Uses quantum-resistant cryptographic primitives

Anatomy of a YAK:// Link

YAKMESH uses human-readable iO names instead of ugly hashes: 

yak://qubit-lattice-prism/path/to/file.txt
  • yak:// — Protocol identifier
  • qubit-lattice-prism — iO name (human-readable content address)
  • /path/to/file.txt — Optional path within the content

💡 Why iO names? Instead of cryptographic hashes like "QmX7k2n9...", YAKMESH derives a 3-word name from a 256-word quantum-themed wordlist. The name is deterministic — the same content always produces the same iO name. Easy to share verbally!

1 Ensure YAKMESH is Running

Before using the yak:// protocol, make sure your YAKMESH node is running: 

# Check if YAKMESH is running
yakmesh status

# Start if needed
yakmesh start

You should see a status indicating the node is active and connected to the mesh.

2 Register the Protocol Handler

To open yak:// links directly from your browser, register YAKMESH as the protocol handler: 

# Register yak:// protocol with your system
yakmesh yak register-handler

# Output: 
# ✓ Protocol handler registered
# You can now open yak:// links in your browser

Note: On Windows, this adds a registry entry. On macOS/Linux, it registers with xdg-open or Launch Services. You may need admin/sudo privileges.

3 Share Content

You can share files, folders, or entire directories using the yak:// protocol:

Share a Single File

# Register a single file
yakmesh yak add myfile.txt

# Output:
# ✓ File added to YAK network
# Link: yak://photon-cipher-node/myfile.txt
# iO code: photon-cipher-node

Share a Directory

# Register an entire directory (recursive)
yakmesh yak add ./my-website/

# Output:
# ✓ Directory added (42 files, 2.3 MB)
# Link: yak://qubit-lattice-prism/
# 
# Individual files accessible:
#   yak://qubit-lattice-prism/index.html
#   yak://qubit-lattice-prism/css/style.css
#   yak://qubit-lattice-prism/images/logo.png

Programmatic (JavaScript)

import { createNode } from 'yakmesh';

async function shareContent() {
  const node = await createNode();
  await node.start();
  
  // Share a file
  const result = await node.yak.add('./document.pdf');
  console.log('File link:', result.yakUrl);
  // yak://fermion-hash-crystal/document.pdf
  console.log('iO code:', result.ioName);
  // fermion-hash-crystal
  
  // Share a directory
  const dirResult = await node.yak.add('./my-website/', { 
    recursive: true 
  });
  console.log('Directory link:', dirResult.yakUrl);
  // yak://qubit-lattice-prism/
  
  // Share with metadata
  const richResult = await node.yak.add('./photo.jpg', {
    name: 'Vacation Photo',
    description: 'Beach sunset',
    tags: ['photo', 'vacation', '2025']
  });
  console.log('Share this iO code:', richResult.ioName);
  // Just tell your friend: "hadron-merkle-wave"
}

shareContent();

4 Retrieve Content

Retrieving content from a yak:// link is just as easy:

Via CLI

# Download using iO name (human-readable)
yakmesh yak get yak://hadron-merkle-wave/myfile.txt

# Output:
# ✓ Resolving iO name: hadron-merkle-wave
# ✓ Downloading from 3 peers...
# ✓ Saved to: ./myfile.txt (1.2 KB)

# Download to specific location
yakmesh yak get yak://hadron-merkle-wave/myfile.txt -o ~/Downloads/

# Download a directory
yakmesh yak get yak://qubit-lattice-prism/ -o ./website-copy/

Via Browser

If you registered the protocol handler, just paste the yak:// link in your browser:

yak://hadron-merkle-wave/myfile.txt

Your YAKMESH node will intercept the request and serve the content locally.

Programmatic (JavaScript)

import { createNode } from 'yakmesh';

async function retrieveContent() {
  const node = await createNode();
  await node.start();
  
  // Get file content using iO name
  const content = await node.yak.get('yak://hadron-merkle-wave/myfile.txt');
  console.log('Content:', content.toString());
  
  // Stream large files
  const stream = await node.yak.getStream('yak://photon-cipher-node/video.mp4');
  stream.pipe(fs.createWriteStream('./video.mp4'));
  
  // Get metadata without downloading
  const meta = await node.yak.stat('yak://qubit-lattice-prism/');
  console.log('Size:', meta.size);
  console.log('Files:', meta.files);
  console.log('Peers:', meta.providers.length);
  console.log('iO name:', meta.ioName);
}

retrieveContent();

5 Useful CLI Commands

Here's a quick reference of yak:// CLI commands:

Command Description
yakmesh yak add <path> Add file/directory and get yak:// link
yakmesh yak get <link> Download content from yak:// link
yakmesh yak stat <link> Show metadata (size, peers, etc.)
yakmesh yak ls <link> List contents of a directory link
yakmesh yak pin <link> Pin content locally (prevent garbage collection)
yakmesh yak unpin <link> Unpin content (allow garbage collection)
yakmesh yak pins List all pinned content
yakmesh yak register-handler Register yak:// protocol with OS

🔬 How It Works

When you share content with yak://:

  1. 1. Content is hashed: Your file/directory is processed through NAKPAK (YAKMESH's content-addressing system) to generate a unique cryptographic fingerprint.
  2. 2. iO name derived: The hash is converted to a human-readable 3-word name using a 256-word quantum-themed wordlist. Same content = same name, always.
  3. 3. Announced to the network: Your node announces that it has this content, making it discoverable by other nodes.
  4. 4. Verified on retrieval: When someone fetches the content, their node verifies the cryptographic fingerprint matches — guaranteeing integrity.

🔧 Troubleshooting

  • Link not found / No peers?
    The original node sharing the content must be online. Check with yakmesh yak stat <link>
  • Protocol handler not working?
    Try running yakmesh yak register-handler with admin privileges.
  • Download stuck?
    Check your mesh connection: yakmesh mesh peers
