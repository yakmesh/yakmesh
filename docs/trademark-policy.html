Trademark Usage Policy

The YAKMESH name, the "Climbing Yak" logo, and the tagline "Sturdy & Secure" are trademarks of the YAKMESH Project (PeerQuanta), based in San Angelo, Texas.

Official Logo Usage

The official YAKMESH emblem may only be used to identify:

  • Official YAKMESH software distributions
  • Official YAKMESH network nodes
  • Official YAKMESH documentation

Forks and Derivative Works

If you fork the YAKMESH repository or create derivative works:

❌ You MUST

  • Remove the official YAKMESH logo
  • Remove YAKMESH branding
  • Rename your software

✅ You MAY

  • State "Based on YAKMESH technology"
  • State "Powered by YAKMESH"
  • Use the "Powered by" badge

Prohibited Uses

You may NOT use the YAKMESH name, logo, or branding in any way that:

  • Suggests official endorsement or affiliation where none exists
  • Creates confusion about the source of the software
  • Implies that your fork is the official YAKMESH project
  • Damages the reputation of the YAKMESH project
