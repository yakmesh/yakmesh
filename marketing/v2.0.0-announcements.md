**Text:**
```
Yakmesh is a P2P mesh network for decentralized apps. Today we're releasing v2.0.0 with a complete security overhaul.

The core idea: Instead of trusting certificate authorities, we verify identity through 7 independent cryptographic gates. Every gate must pass for a message to be trusted.

**The 7 Gates (NAMCHE Gateway):**
- Cryptographic: Valid ML-DSA-65 signature
- Format: Valid identity document
- Temporal: Within clock tolerance
- Domain: DNS TXT verification
- Mesh: 3+ peer endorsements
- Behavioral: Trust history score
- Freshness: Liveliness within 5 minutes

**Key Design Decisions:**

1. Post-quantum from day one (ML-DSA-65)
2. Trust is graduated (5 tiers), not binary
3. Social + cryptographic verification combined
4. Self-sovereign identity (DOKO documents)

**Why this matters:**

When a CA is compromised, so is everything it signed. With mesh verification, compromising one node doesn't compromise the network — you'd need to subvert multiple independent verifiers.

100% open source, MIT licensed, no tracking.
