# Product Hunt Launch

**Product Name:** YAKMESH™

**Tagline:** Post-quantum P2P mesh network – Sturdy & Secure

**Description:**

YAKMESH is a high-resiliency, decentralized mesh network built with quantum-resistant cryptography at its core. Unlike traditional P2P systems that rely on blockchain consensus or trusted validators, YAKMESH derives network identity directly from the validation code hash – *code is the authority*.

**How it works:**
Same code = Same network identity = Trustless coordination

**Key Features:**
🔐 **Post-quantum signatures** (ML-DSA-65 + SLH-DSA backup, NIST FIPS 204/205)
🛡️ **Dual algorithm defense** – Lattice-based + hash-based for ultimate security
🔮 **Self-verifying oracle** – No external trust required
🌐 **WebSocket mesh** with gossip protocol
⏱️ **Precision timing** – Atomic clock, GPS, PTP support
📊 **Real-time dashboard** – Monitor crypto, oracle, and network health
🔌 **Plugin architecture** for custom integrations

**First Comment (Maker):**

Hey Product Hunt! 🦬

I built YAKMESH because I wanted a simpler alternative to blockchain for distributed coordination. The core idea: what if we derived trust from the code itself?

The result is a mesh network where your identity comes from a cryptographic hash of your validation rules. Everyone running identical code is automatically on the same network. Change the code, and you fork to a new network – no votes, no governance, no politics.

**Why post-quantum?** RSA/ECDSA won't survive quantum computers. We use ML-DSA-65 (NIST FIPS 204) as primary signatures, PLUS SLH-DSA (FIPS 205) hash-based backup signatures for defense-in-depth. If lattice-based crypto ever breaks, your data is still protected by hash-based crypto.

The name? Yaks are sturdy mountain animals that thrive in harsh conditions. That's what we're building – a network that's sturdy and secure, ready for the post-quantum era.
