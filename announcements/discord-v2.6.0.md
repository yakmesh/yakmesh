## 📚 What's GRANTH?

Every YAKMESH npm package now ships with **complete documentation built-in**:

- **Hash-verified** — Each doc file has a SHA3-256 hash
- **Offline access** — Works without internet
- **Tamper-proof** — Bundle hash proves integrity
- **iO naming** — Human-readable identifiers (e.g., "lens-anyon-plasmon")

```javascript
import { BUNDLE_HASH, FILES } from 'yakmesh/embedded-docs/bundle.js';
// Docs are verified at load time!
```
