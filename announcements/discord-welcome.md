- Quantum computers can't break what's built to resist them

### 🌐 True Decentralization
- **No central servers** — Peer-to-peer by design
- **Gossip protocol** — Messages propagate organically
- **Self-sovereign identity** — You own your keys

### 🧭 The NAMCHE Gateway
Seven mathematical gates that verify identity WITHOUT certificate authorities:
1. Structural validity
2. Temporal validity (timing analysis)
3. Cryptographic verification
4. Behavioral assessment
5. Network consensus
6. Historical reputation
7. Final oracle judgment

### 🏆 Trust Tiers
Nodes earn trust through behavior, not authority:
```
UNTRUSTED → PENDING → VERIFIED → TRUSTED → GUARDIAN
```

### 🔬 Hardware Attestation
AES-NI timing analysis proves nodes run on **real silicon** — not VMs, not emulators, not botnets.

### ⚖️ Silicon Parity

## 🚀 Get Started

### Installation
```bash
npm install yakmesh
```

### Basic Usage
```javascript
import { YakmeshNode } from 'yakmesh';

const node = new YakmeshNode({
  node: { name: 'My Node' },
  network: { httpPort: 3000, wsPort: 9001 },
});

await node.start();
console.log('🦬 Node is running!');
```

### CLI
```bash
npx yakmesh init      # Initialize a new node
npx yakmesh start     # Start the node
npx yakmesh status    # Check node status
```
