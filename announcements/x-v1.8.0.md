### Tweet 3
How it works:

1️⃣ Node exposes beacon at /.well-known/yakmesh/beacon
2️⃣ SHERPA crawls known endpoints
3️⃣ Discovers new peers from each beacon
4️⃣ Builds scored registry (best peers first)
5️⃣ Connects via WebSocket mesh

No central authority!
