Host a Website

15 min

Serve your site locally and expose it to the internet

This tutorial walks you through hosting a complete static website using YAKMESH — from installation to making your site accessible worldwide, no cloud providers needed.

📚 What You'll Learn

  • • Install and initialize YAKMESH on your computer
  • • Understand the htdocs folder structure
  • • Create and configure your website
  • • Start the YAKMESH server
  • • Access your site locally and expose it to the internet

Prerequisites

  • ✓ Node.js 20 or later (22 LTS recommended)
  • ✓ npm package manager
  • ✓ A text editor (VS Code, Sublime, etc.)
  • ✓ Basic understanding of HTML/CSS (helpful but not required)

1 Install YAKMESH

Open your terminal and install YAKMESH globally from npm. This gives you access to the yakmesh command from anywhere. 

npm install -g yakmesh

Alternatively, you can use npx to run commands without global installation: 

npx yakmesh --version

2 Initialize Your Node

Create a new directory for your project and initialize YAKMESH inside it: 

mkdir my-website
cd my-website
yakmesh init

This creates the following structure: 

my-website/
├── yakmesh.config.js    # Node configuration
├── data/                # Node data (identity, logs, etc.)
└── htdocs/              # Your website files go here!

3 Understand the htdocs Folder

The htdocs/ folder is your web root — everything inside this folder is served by YAKMESH. Think of it like a traditional Apache htdocs or Nginx html folder.

How URLs map to files:

  • http://localhost:3000/ → htdocs/index.html
  • http://localhost:3000/about → htdocs/about.html
  • http://localhost:3000/css/style.css → htdocs/css/style.css
  • http://localhost:3000/images/logo.png → htdocs/images/logo.png

Tip: You can change the web root directory in yakmesh.config.js if you prefer a different folder name.

4 Create Your Website

Let's create a simple website. Create an index.html file inside the htdocs folder: 

# Create the file (or use your text editor)
touch htdocs/index.html

Add this content to htdocs/index.html: 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My YAKMESH Site</title>
    <style>
        body {
            font-family: system-ui, sans-serif;
            max-width: 800px;
            margin: 0 auto;
            padding: 2rem;
            background: #1e293b;
            color: #f1f5f9;
        }
        h1 { color: #10b981; }
        a { color: #34d399; }
    </style>
</head>
<body>
    <h1>Welcome to My Site!</h1>
    <p>This website is hosted on YAKMESH — a post-quantum secure mesh network.</p>
    <p>No cloud providers. No central servers. Just you and the mesh.</p>
</body>
</html>

5 Configure Your Server (Optional)

Open yakmesh.config.js to customize your server settings. Here's what a typical web hosting configuration looks like: 

// yakmesh.config.js
module.exports = {
  // Server settings
  port: 3000,                    // Web server port
  host: '0.0.0.0',               // Listen on all interfaces
  
  // Web hosting settings
  webRoot: './htdocs',           // Web files directory
  indexFile: 'index.html',       // Default index file
  
  // Security settings
  enableCORS: true,              // Allow cross-origin requests
  maxRequestSize: '10mb',        // Max upload size
  
  // Mesh network settings
  enableMesh: true,              // Connect to YAKMESH network
  enableAnnex: true,             // Enable ANNEX gateway
  
  // Logging
  logLevel: 'info',              // debug, info, warn, error
};

The defaults work for most cases. Only modify if you need specific behavior.

6 Start the Server

You're ready to launch! Start your YAKMESH server: 

yakmesh start

You should see output like this: 

🐃 Starting Yakmesh Node...

🔐 Securing codebase...
✓ Codebase locked: 65 files protected
🌐 Starting web server...
✓ Web server running at http://localhost:3000
✓ htdocs/ folder mounted as web root
✓ Yakmesh Node is running!
   Dashboard: http://localhost:3000/dashboard

7 Access Your Site

Open your browser and navigate to:

http://localhost:3000

You should see your website! The dashboard is available at:

http://localhost:3000/dashboard

8 Expose to the Internet

To make your site accessible from anywhere, you have several options:

Option A: ANNEX Gateway (Recommended)

ANNEX provides a built-in tunnel that gives your site a public URL without port forwarding: 

# Enable ANNEX in your config, then restart
yakmesh restart

# Your site will be available at a .yak.link address
# Check the dashboard for your public URL

Option B: YAK Protocol Link

Share content via the yak:// protocol — cryptographic links that identify your content globally: 

# Register your htdocs folder
yakmesh yak register ./htdocs

# Output: yak://abc123...xyz/
# Anyone with YAKMESH can access this link

Option C: Direct Port Forwarding

For advanced users, forward port 3000 on your router:

  1. 1. Log into your router's admin panel
  2. 2. Find "Port Forwarding" settings
  3. 3. Forward external port 80 → internal 3000
  4. 4. Your site is now at http://your-public-ip/

💻 Programmatic Hosting (JavaScript)

You can also start a YAKMESH web server programmatically in your Node.js applications: 

import { createNode } from 'yakmesh';

async function startWebsite() {
  // Create and configure the node
  const node = await createNode({
    port: 3000,
    webRoot: './htdocs',
    enableMesh: true,
    enableAnnex: true
  });
  
  // Start the server
  await node.start();
  
  console.log('Website running at http://localhost:3000');
  console.log('Dashboard at http://localhost:3000/dashboard');
  
  // Get your public URL (if ANNEX is enabled)
  const publicUrl = await node.getPublicUrl();
  if (publicUrl) {
    console.log('Public URL:', publicUrl);
  }
  
  // Register content with the yak:// protocol
  const yakLink = await node.yak.register('./htdocs');
  console.log('YAK Link:', yakLink);
}

startWebsite().catch(console.error);

🔧 Troubleshooting

  • Port 3000 already in use?
    Change the port in yakmesh.config.js or use: yakmesh start --port 3001
  • Site shows 404?
    Make sure you have an index.html file in your htdocs folder.
  • Can't access from other devices on LAN?
    Ensure host is set to '0.0.0.0' in your config, and check your firewall settings.
