Mobile Access

10 min

View and manage your node from your phone

Access your YAKMESH dashboard from anywhere, install it as an app, and stay connected on the go.

📋 What You'll Learn

  • • Access your dashboard on the same network
  • • Set up remote access with Tailscale or ZeroTier
  • • Install the PWA on your phone's home screen
  • • Understand what you can manage remotely
  • • Security best practices for mobile access
1

Access on Your Home Network

When your phone is on the same WiFi network as your YAKMESH node, you can access it directly.

Find Your Node's Address

# On your YAKMESH node, find the local IP:
hostname -I
# Example output: 192.168.1.100

# Or check the dashboard startup message:
# Dashboard: http://192.168.1.100:3000/dashboard

Open in Mobile Browser

  1. Connect your phone to the same WiFi network
  2. Open your mobile browser (Safari, Chrome, Firefox)
  3. Enter: http://192.168.1.100:3000/dashboard
  4. Bookmark the page for quick access

💡 Use mDNS for Easier Access

If your node has a hostname, try: http://yakmesh-node.local:3000
This works on most home networks without remembering the IP address.

2

Remote Access with Tailscale

Tailscale creates a secure private network that works from anywhere. Free for personal use.

Install on Your YAKMESH Node

# Install Tailscale (Linux/Raspberry Pi)
curl -fsSL https://tailscale.com/install.sh | sh

# Start and authenticate
sudo tailscale up

# Follow the link to authenticate in your browser
# Note your Tailscale IP (usually 100.x.x.x)

Install on Your Phone

  1. Download Tailscale from App Store (iOS) or Play Store (Android)
  2. Sign in with the same account you used on your node
  3. Enable the VPN when prompted
  4. Your phone is now on the same virtual network as your node!

Access Your Dashboard Remotely

# Find your node's Tailscale IP
tailscale ip -4
# Example: 100.64.0.1

# Access from your phone (even on cellular):
http://100.64.0.1:3000/dashboard

✨ Tailscale Benefits

  • • No port forwarding needed - works behind any NAT/firewall
  • • End-to-end encrypted - WireGuard-based security
  • • Always connected - access from anywhere in the world
  • • Free tier - up to 100 devices for personal use
3

Alternative: ZeroTier

ZeroTier is another excellent option for creating a virtual private network.

Setup Overview

# Install ZeroTier on your node
curl -s https://install.zerotier.com | sudo bash

# Join a network (create one at my.zerotier.com first)
sudo zerotier-cli join <network-id>

# Check your ZeroTier IP
sudo zerotier-cli listnetworks
  1. Create a free account at my.zerotier.com
  2. Create a new network and note the Network ID
  3. Install ZeroTier on your node and phone
  4. Join the same network on both devices
  5. Authorize both devices in the ZeroTier dashboard
  6. Access your node using its ZeroTier IP
4

Install as a Phone App (PWA)

The YAKMESH dashboard is a Progressive Web App (PWA). Install it on your home screen for an app-like experience.

iOS (Safari)

  1. Open the dashboard URL in Safari
  2. Tap the Share button (square with arrow)
  3. Scroll down and tap "Add to Home Screen"
  4. Edit the name if desired, then tap "Add"
  5. The YAKMESH icon now appears on your home screen!

Android (Chrome)

  1. Open the dashboard URL in Chrome
  2. Tap the three-dot menu (⋮)
  3. Tap "Add to Home screen" or "Install app"
  4. Confirm the installation
  5. Find YAKMESH in your app drawer!

📲 PWA Features

  • • Full-screen mode - no browser UI clutter
  • • Offline support - cached pages work without connection
  • • Push notifications - get alerts about your node (if enabled)
  • • Fast launch - opens directly without typing URLs
5

What You Can Do Remotely

Full Access

  • ✅ View Dashboard - See node status, peers, network health
  • ✅ Monitor Metrics - Uptime, bandwidth, storage usage
  • ✅ Browse Files - View shared content via YAK:// links
  • ✅ Check Peers - See connected peers and their status
  • ✅ View Logs - Debug issues remotely

Management Actions

  • ✅ Connect/Disconnect Peers - Manage peer connections
  • ✅ Share Content - Generate YAK:// links
  • ✅ Update Settings - Change configuration (with API)
  • ⚠️ Upload Files - Limited by mobile connection speed
  • ❌ Restart Node - Requires SSH access (see below)

SSH for Advanced Control

For full admin access, use an SSH app on your phone:

  • • iOS: Termius, Prompt, Blink Shell
  • • Android: Termux, JuiceSSH, ConnectBot
# Connect via Tailscale IP
ssh pi@100.64.0.1

# Restart YAKMESH
sudo systemctl restart yakmesh
6

Security Considerations

Accessing your node remotely adds convenience but requires security awareness.

Best Practices

✅ DO: Use VPN-based solutions

Tailscale and ZeroTier encrypt all traffic and don't expose ports to the internet.

✅ DO: Enable authentication

Configure dashboard authentication in yakmesh.config.js: 

auth: {
  enabled: true,
  username: 'admin',
  password: 'your-secure-password',
}

✅ DO: Use HTTPS when possible

If accessing over the internet, set up SSL (see Domain Setup tutorial).

❌ DON'T: Expose ports directly to internet

Avoid port forwarding 3000 or 9001 without authentication and SSL. Use Tailscale instead.

❌ DON'T: Use public WiFi without VPN

Always use Tailscale/ZeroTier when on untrusted networks. They encrypt your traffic.

❌ DON'T: Save passwords in browser on shared devices

Use a password manager instead, and enable biometric lock on your phone.

📋 Quick Reference

Access Method Best For Setup Difficulty
Local WiFi Home use, no internet needed Easy
Tailscale Remote access without port forwarding Easy
ZeroTier Self-hosted network option Medium
Domain + HTTPS Public access, sharing links Advanced
