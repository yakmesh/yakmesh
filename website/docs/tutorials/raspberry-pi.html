Running on Raspberry Pi

20 min

Set up a dedicated always-on YAKMESH node

Turn a Raspberry Pi into a 24/7 YAKMESH node. Low power, always connected, perfect for mesh networking.

📋 What You'll Learn

  • • Choose the right Raspberry Pi hardware
  • • Install and configure Raspberry Pi OS
  • • Install Node.js on ARM architecture
  • • Install and configure YAKMESH
  • • Set up auto-start on boot with systemd
  • • Optimize for low power and reliability
1

Hardware Requirements

Recommended Hardware

Component Minimum Recommended
Raspberry Pi Model Pi 3B+ (1GB) Pi 4 (4GB) or Pi 5
Storage 16GB microSD 32GB+ microSD or SSD
Power Supply 5V 2.5A 5V 3A (USB-C for Pi 4/5)
Cooling Heatsinks Active fan or case with fan
Network WiFi Ethernet (more reliable)

💡 Why Pi 4 with 4GB+?

YAKMESH uses post-quantum cryptography which requires more memory than classical crypto. The Pi 4's improved CPU and RAM handle ML-DSA-65 signatures efficiently.

2

Install Raspberry Pi OS

Download and Flash

  1. Download Raspberry Pi Imager
  2. Insert your microSD card into your computer
  3. Open Raspberry Pi Imager and select:
    • OS: Raspberry Pi OS Lite (64-bit) - no desktop needed
    • Storage: Your microSD card
  4. Click the gear icon (⚙️) for advanced options:
    • Set hostname: yakmesh-node
    • Enable SSH with password or public key
    • Set username and password
    • Configure WiFi (if not using Ethernet)
    • Set locale and timezone
  5. Click Write and wait for completion

First Boot

# Insert SD card into Pi and power on
# Wait 2-3 minutes for first boot to complete
# Find your Pi's IP address from your router, or use:
ping yakmesh-node.local

# SSH into your Pi
ssh pi@yakmesh-node.local
# Enter your password when prompted

Initial System Update

# Update package lists and upgrade
sudo apt update && sudo apt upgrade -y

# Install essential tools
sudo apt install -y curl git build-essential

# Reboot to apply any kernel updates
sudo reboot
3

Install Node.js on ARM

YAKMESH requires Node.js 20 or later. We'll use NodeSource for the latest ARM builds.

Install Node.js 22 LTS

# Add NodeSource repository for Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -

# Install Node.js
sudo apt install -y nodejs

# Verify installation
node --version   # Should show v22.x.x
npm --version    # Should show 10.x.x

Alternative: Using nvm (Node Version Manager)

# Install nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Reload shell
source ~/.bashrc

# Install Node.js 22
nvm install 22
nvm use 22
nvm alias default 22

⚠️ ARM Architecture Note

Raspberry Pi uses ARM64 (aarch64) architecture. All npm packages with native bindings will be compiled during installation, which may take longer than on x86.

4

Install YAKMESH

Create Project Directory

# Create a dedicated directory
mkdir -p ~/yakmesh
cd ~/yakmesh

# Initialize npm project
npm init -y

# Install YAKMESH
npm install yakmesh

Initialize Node

# Generate node identity and config
npx yakmesh init

# This creates:
# - yakmesh.config.js (configuration)
# - data/ directory (node data and keys)

Configure for Pi

Edit yakmesh.config.js for optimal Pi performance: 

// yakmesh.config.js - Raspberry Pi optimized
export default {
  node: {
    name: 'pi-yakmesh-node',
  },
  
  server: {
    host: '0.0.0.0',  // Accept connections from network
    port: 3000,
  },
  
  websocket: {
    port: 9001,
  },
  
  // Reduce memory usage on constrained devices
  performance: {
    maxPeers: 50,           // Limit peer connections
    cacheSize: '256mb',     // Reduce cache for 1GB Pi
    gcInterval: 300000,     // Garbage collect every 5 min
  },
  
  // Enable logging to file for debugging
  logging: {
    level: 'info',
    file: './data/yakmesh.log',
  },
};

Test Run

# Start YAKMESH to verify it works
npx yakmesh start

# You should see the startup messages
# Press Ctrl+C to stop for now
5

Auto-Start on Boot (systemd)

Create a systemd service so YAKMESH starts automatically when the Pi boots.

Create Service File

# Create the systemd service file
sudo nano /etc/systemd/system/yakmesh.service

Paste this content:

[Unit]
Description=YAKMESH Node
Documentation=https://yakmesh.com/docs
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/yakmesh
ExecStart=/usr/bin/npx yakmesh start
Restart=always
RestartSec=10

# Security hardening
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=read-only
ReadWritePaths=/home/pi/yakmesh/data

# Resource limits
MemoryMax=1G
CPUQuota=80%

# Environment
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target

Enable and Start Service

# Reload systemd to recognize new service
sudo systemctl daemon-reload

# Enable auto-start on boot
sudo systemctl enable yakmesh

# Start the service now
sudo systemctl start yakmesh

# Check status
sudo systemctl status yakmesh

Useful Service Commands

# View logs
sudo journalctl -u yakmesh -f

# Restart service
sudo systemctl restart yakmesh

# Stop service
sudo systemctl stop yakmesh

# Disable auto-start
sudo systemctl disable yakmesh
6

Power and Networking Tips

Stable Power Supply

  • • Use the official Raspberry Pi power supply (5V 3A for Pi 4/5)
  • • Avoid USB hubs or phone chargers - they may cause undervoltage
  • • Consider a UPS HAT for power outage protection
  • • Check for undervoltage warnings: vcgencmd get_throttled

Network Reliability

  • • Use Ethernet whenever possible - WiFi can be unreliable for 24/7 operation
  • • If using WiFi, configure a static IP to prevent DHCP issues
  • • Consider a powered USB Ethernet adapter for gigabit speeds on Pi 3

Static IP Configuration

# Edit dhcpcd configuration
sudo nano /etc/dhcpcd.conf

# Add at the end (adjust for your network):
interface eth0
static ip_address=192.168.1.100/24
static routers=192.168.1.1
static domain_name_servers=1.1.1.1 8.8.8.8

# Restart networking
sudo systemctl restart dhcpcd

Firewall Configuration

# Install and configure ufw
sudo apt install -y ufw

# Allow SSH (important - don't lock yourself out!)
sudo ufw allow ssh

# Allow YAKMESH ports
sudo ufw allow 3000/tcp    # Dashboard
sudo ufw allow 9001/tcp    # WebSocket

# Enable firewall
sudo ufw enable

# Check status
sudo ufw status
7

Performance Considerations

Temperature Monitoring

Post-quantum crypto is CPU-intensive. Monitor temperatures to prevent throttling: 

# Check current temperature
vcgencmd measure_temp

# Monitor continuously
watch -n 1 vcgencmd measure_temp

# Install htop for system monitoring
sudo apt install -y htop

🌡️ Temperature Guidelines

  • • <60°C: Normal operation
  • • 60-80°C: Warm but acceptable with cooling
  • • >80°C: Throttling begins - improve cooling
  • • >85°C: Heavy throttling - add active cooling

SSD for Better Performance

For maximum reliability and speed, boot from an SSD instead of microSD: 

# Check if your Pi supports USB boot (Pi 4/5)
vcgencmd bootloader_version

# Use Raspberry Pi Imager to flash OS to SSD
# Then update boot order in raspi-config:
sudo raspi-config
# Advanced Options → Boot Order → USB Boot

Memory Optimization

# Reduce GPU memory (headless server doesn't need it)
sudo nano /boot/config.txt

# Add or modify:
gpu_mem=16

# Enable zram for better memory management
sudo apt install -y zram-tools
sudo systemctl enable zramswap
sudo reboot

✅ Access Your Node

Once running, access your YAKMESH dashboard from any device on your network: 

# From your computer's browser, go to:
http://yakmesh-node.local:3000/dashboard

# Or use the IP address:
http://192.168.1.100:3000/dashboard

Verify Node Health

# Check node status via API
curl http://yakmesh-node.local:3000/health

# Expected response:
{
  "status": "healthy",
  "network": "your-network-name",
  "algorithm": "ML-DSA-65",
  "peers": 5,
  "uptime": "2h 15m"
}

🎉 Your Pi Node is Ready!

Your Raspberry Pi is now running a dedicated YAKMESH node 24/7. It will:

  • • Automatically start when the Pi boots
  • • Restart if it crashes
  • • Connect to peers and participate in the mesh
  • • Serve your dashboard on port 3000

🔧 Maintenance Tips

Keep software updated

sudo apt update && sudo apt upgrade -y
cd ~/yakmesh && npm update yakmesh

Backup your node identity

# Copy to your computer
scp -r pi@yakmesh-node.local:~/yakmesh/data ./yakmesh-backup

Check logs for issues

sudo journalctl -u yakmesh --since "1 hour ago"
