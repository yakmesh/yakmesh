Join the Mesh Network

10 min

Connect to the decentralized YAKMESH network

The mesh network is the backbone of YAKMESH — a fully decentralized peer-to-peer network with no central servers. This tutorial shows you how to join, monitor peers, and understand what the mesh provides.

🌐 What is the Mesh Network?

The YAKMESH network is a peer-to-peer mesh where every node connects directly to other nodes — no central servers required. Think of it like a spider web: if one strand breaks, messages can still travel through other paths.

🔐
Post-Quantum Secure

All connections use quantum-resistant cryptography

🌍
Globally Distributed

Peers connect across countries and continents

🚫
No Central Point of Failure

Network continues even if nodes go offline

🔄
Self-Healing

Automatically routes around failed connections

1 Enable Mesh Networking

Mesh networking is enabled by default when you start YAKMESH. Verify it's active: 

# Check YAKMESH status
yakmesh status

# Output:
# 🐃 Yakmesh Node Status
# ──────────────────────
# Node ID:    yak-a7f2x9...
# Status:     Running
# Uptime:     2h 34m
# 
# 🕸️ Mesh Network
# ──────────────────────
# Status:     Connected
# Network:    yakmesh-main
# Peers:      12 connected
# DHT:        Active (2,847 entries)

If mesh is disabled, enable it in your configuration: 

// yakmesh.config.js
module.exports = {
  // Enable mesh networking
  enableMesh: true,
  
  // Optional: configure mesh behavior
  mesh: {
    // Maximum number of peer connections
    maxPeers: 50,
    
    // Enable peer discovery
    enableDHT: true,
    enableMDNS: true,  // Local network discovery
    
    // Connection settings
    dialTimeout: 30000,  // 30 seconds
    keepAlive: 60000,    // 1 minute
  }
};

2 Check Your Peers

View your current peer connections: 

# List connected peers
yakmesh mesh peers

# Output:

# ─────────────────────────────────────────────────────────
# yak-b3x7f2...       | 192.168.1.5:3000  | 2ms     | 0.95
# yak-k9p2m1...       | 45.33.21.89:3000  | 47ms    | 0.82
# yak-r7t4w3...       | 203.0.113.42:3001 | 112ms   | 0.71
# yak-m2n8v6...       | 10.0.0.15:3000    | 1ms     | 0.88

Understanding the Output

  • ID: The peer's unique node identifier (truncated for display)
  • Address: IP address and port of the peer
  • Latency: Round-trip time to the peer in milliseconds
  • Trust: KARMA trust score (0.0 - 1.0) based on behavior history

Get Detailed Peer Info

3 Discover New Peers

YAKMESH uses multiple methods to discover peers automatically:

  • DOKO DHT: Distributed Hash Table for global peer discovery
  • mDNS: Local network discovery (finds peers on your LAN)
  • Peer Exchange (PEX): Connected peers share their peer lists

Manual Peer Connection

You can also connect to a specific peer manually: 

# Connect to a peer by address
yakmesh mesh connect 45.33.21.89:3000

# Output:
# ✓ Connected to yak-k9p2m1...
# Latency: 47ms
# Trust: 0.82

Programmatic Connection (JavaScript)

import { createNode } from 'yakmesh';

async function connectToPeers() {
  const node = await createNode();
  await node.start();
  
  // Get current peers
  const peers = await node.mesh.peers();
  console.log('Connected to', peers.length, 'peers');
  
  // Connect to a specific peer
  await node.mesh.connect('45.33.21.89:3000');
  
  // Listen for new peer connections
  node.mesh.on('peer:connect', (peer) => {
    console.log('New peer:', peer.id);
    console.log('Address:', peer.address);
  });
  
  // Listen for peer disconnections
  node.mesh.on('peer:disconnect', (peer) => {
    console.log('Peer left:', peer.id);
  });
  
  // Get peer count
  const count = await node.mesh.peerCount();
  console.log('Total peers:', count);
}

connectToPeers();

🎁 What the Mesh Provides

Once connected to the mesh, you gain access to these capabilities:

📡 Content Distribution

Your yak:// content is discoverable by anyone on the mesh. The more peers connected, the faster content propagates.

🔍 Decentralized Search

Search for content across the network without relying on centralized search engines. Uses DOKO's distributed hash table.

💬 Mesh Messaging

Send encrypted messages to any peer on the network. Messages route through the mesh automatically.

☯️ Trust & Reputation

KARMA scores track peer behavior. Good actors earn trust; bad actors are isolated. This happens automatically through mesh observations.

⏰ Synchronized Time

MANI provides consensus-based time synchronization across the mesh, independent of centralized NTP servers.

🌉 ANNEX Gateway

Bridge to the regular internet. Get public URLs for your content without port forwarding or dynamic DNS.

📋 Mesh CLI Commands

Quick reference for mesh-related commands:

Command Description
yakmesh mesh status Show mesh network status
yakmesh mesh peers List all connected peers
yakmesh mesh peer <id> Show details for a specific peer
yakmesh mesh connect <addr> Connect to a peer manually
yakmesh mesh disconnect <id> Disconnect from a peer
yakmesh mesh ban <id> Ban a peer (blocks future connections)
yakmesh mesh unban <id> Unban a previously banned peer
yakmesh mesh discover Trigger peer discovery manually
yakmesh mesh stats Show bandwidth and connection statistics

🔧 Troubleshooting

  • No peers connecting?
    Check your firewall allows incoming connections on port 3000. Try yakmesh mesh discover
  • Mesh status shows "Disconnected"?
    Ensure enableMesh: true in your config and restart the node.
  • High latency to all peers?
    Check your internet connection. Try enabling enableMDNS: true to find local peers.
  • Peers keep disconnecting?
    Increase mesh.keepAlive timeout in your config.
